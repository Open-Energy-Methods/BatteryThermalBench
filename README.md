# BatteryThermalBench

**Research stage: literature and experimental-data qualification only.**

This independent Open Energy Methods research project is investigating defensible electro-thermal and thermal-management benchmarks for lithium-ion cells and modules under fast charging. **No solver, cooling-performance comparison, validated parameter set, or battery-safety claim exists yet.**

Work begins with a paper-by-paper source review, software and experimental data audit, and a pre-registered verification and validation framework. Only after these are qualified will numerical development start.
